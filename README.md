# QPET Interactive Prototype
QPET is an ASP.NET Core MVC interactive prototype developed to demonstrate the proposed QPET website and admin system. 

## How to Run the Application
##Requirements
- Visual Studio 2022
- .NET SDK
- A modern web browser

### Running in Visual Studio
1. Clone or download the repository.
2. Open the QPET solution in Visual Studio.
3. Allow Visual Studio to restore any NuGet packages.
4. Click the *HTTPS* run button or press 'Ctrl + F5'.
5. The app will open in your default web browser.
